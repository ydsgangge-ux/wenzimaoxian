信号台 · 新手写作说明

从零写一个分支对话故事。读完这份说明，你应该能写出自己的第一个 Lifeline 剧情。

1. 心智模型：把它想成"对讲机剧本"

你写的是一段段对讲机对话。玩家收到一条消息，等一会儿，再收到下一条。在某些关键时刻，玩家要做出选择（点选项，或自由输入文字），故事就走向不同的分支。

所以你只需要做两件事：

  • 把故事拆成一个个 节点（一个场景或一段对话）
  • 每个节点结尾告诉系统：玩家下一步怎么走（选项 / 自由输入 / 自动跳转 / 结局）

2. 最小可运行剧本

下面是一个能跑的最小剧本，复制到编辑器即可：

:: 开场
Alex: 你能听到我吗？飞船坠毁了。
? 你要说什么？
  + 保持冷静 -> 冷静
  + 大哭 -> 哭泣

:: 冷静
Alex: 好，我们一步步来。
-> END

:: 哭泣
Alex: 别哭，听我说…
-> END

看到结构了吗？:: 起一个节点，每行 角色: 文字 是一条消息，? 是选项块，+ 是一个选项，-> 是跳转，-> END 是结局。

3. 七种语法元素

所有语法都有工具栏按钮，新手不要手敲，用工具栏按钮插入：

  • :: 节点名 — 定义一个节点。节点名是唯一标识，建议用"场景_状态"风格，例如 山洞_找到水
  • 角色: 文字 — 一条消息。角色名随意起，文字里可以插入 {变量名} 自动替换成变量值
  • [delay:5m] — 延迟。数字+单位（s秒/m分/h时/d天）。下一条消息会等这个时间再发
  • ? 提示 + + 选项 -> 目标 — 固定选项。玩家只能从列出的选项里选
  • ?? 提示 + ~ 意图 -> 目标 + fallback -> 兜底 — 自由输入。玩家随便打字，AI 判断最接近哪个意图就跳到对应节点。需要填 API Key 才能用
  • [branch] + 条件 -> 目标 + default -> 兜底 — 条件分流。不经过玩家操作，按变量值自动走哪条路
  • -> 目标 或 -> END — 跳转或结局

4. 变量：让故事"记住"发生过什么

变量让你做出"如果玩家之前选了 A，现在走 B 分支"这种逻辑。三件套：

  • 赋值：[set 收束率:+10] 加 10，[set 已见面:=true] 设为 true，[set 名字:=Alex] 设为字符串。可以单独一行（作用于下一条消息），也可以放在选项行里（选了这个选项才赋值）
  • 插值：在消息文字里写 {收束率}，运行时自动替换成当前值
  • 条件：[if 收束率>=80] 放在选项或意图行里，条件不满足时该选项不显示。[branch] 块里每行写 收束率>=80 -> 节点名

支持的比较运算符：== != > < >= <=。布尔值写 true / false。

5. 一个稍完整的例子

:: 开场
Alex: 信号恢复了吗？你能听到我吗？
? 怎么回应？
  + 在的，先看看周围 [set 冷静度:+5] -> 山洞
  + 我害怕，不知道怎么办 [set 冷静度:-5] -> 山洞

:: 山洞
Alex: 我看到了一些奇怪的字。
[delay:3m]
Alex: 字迹写着"出去的人会死"。
{冷静度} >= 50 时你会冷静分析，否则你会慌乱。
[branch]
  冷静度 >= 0 -> 冷静路线
  default -> 慌乱路线

:: 冷静路线
Alex: 我觉得是吓唬人的。
-> END

:: 慌乱路线
Alex: 我必须立刻离开这里！
-> END

6. 左侧节点列表的颜色含义

  • ● 绿色 正常，有出口或结局
  • ● 红色 死路 — 这个节点既不是结局，也没有任何跳转/选项/分流。玩家走到这里会卡住
  • ● 橙色 不可达 — 没有任何节点指向它，玩家根本走不到这里。通常是节点名拼错了

7. 保存机制（重要）

你的剧本会自动保存到浏览器本地存储（每次按键都会保存）。关闭浏览器、断电、重启电脑后再打开 editor.html，内容还在。

但这只在你这台电脑、这个浏览器里。要换电脑、要备份、要分享给别人，必须点顶部的"保存文本"按钮，会下载一个 .lifeline 文件。下次用"打开 .lifeline"按钮载入。

想给别人玩你写的故事？点"导出可发布 H5"，会生成一个独立 HTML 文件，发给别人双击就能玩。

8. 撤销 / 重做

  • Ctrl + Z 撤销（也支持顶部"↶ 撤销"按钮）
  • Ctrl + Y 或 Ctrl + Shift + Z 重做（也支持顶部"↷ 重做"按钮）
  • 历史记录最多保留 200 步

9. 自由输入模式（需要 API Key）

选项模式（?）只让玩家点固定选项，简单可靠。自由输入模式（??）让玩家用自己的话回答，由 AI 判断走哪个分支。这是 Lifeline 最有"对讲机"感觉的地方。

使用步骤：

  • 在节点里写 ?? 提示 开始一个自由输入交互
  • 用 system: 人设描述 告诉 AI 它扮演什么角色（"你是一个被困的宇航员，紧张但理性"）
  • 用 ~ 意图描述 -> 节点 列出可能的意图。AI 只做意图分类，不会替你生成剧情内容，剧情走向完全在你掌控中
  • 用 fallback -> 兜底节点 兜底，AI 判断不出来时走这里
  • 玩家在预览/导出后输入 API Key（DeepSeek 或智谱 GLM）后，输入框才会出现

没填 API Key 时，自由输入会自动退化为按意图列表点选的模式，方便测试。

10. 工作流程建议

  • 第一步：先用纸笔或脑图列出所有节点和分支结构，想清楚有哪些结局
  • 第二步：在编辑器里用工具栏按钮快速搭出骨架（先不写细节文字）
  • 第三步：左侧节点列表全绿（无红/橙）后再开始填充文字
  • 第四步：右侧预览随时点开试玩，发现卡住就回到编辑器改
  • 第五步：满意了点"导出可发布 H5"，发给别人玩

11. 玩家输入名字（代入感）

很多 Lifeline 风格的游戏允许玩家在开始前输入自己的名字，故事里的角色会直接称呼这个名字。语法很简单：

@input: player_name = 请输入你的名字

:: 开场
Alex: 你好，{player_name}，能听到我吗？

@input: 变量名 = 提示文字 放在脚本最前面（任何 :: 节点之前）。预览时会弹出一个输入框，玩家输入的值会存入变量，后面用 {变量名} 插值到对话中。支持同时定义多个输入变量。
