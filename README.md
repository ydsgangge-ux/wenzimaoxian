# 信号台 · Lifeline 编辑器

一个交互式文字冒险游戏的创作工具，灵感来自 Lifeline（生命线）系列。用简单的脚本语法编写对话剧情，实时预览游戏效果。

## 快速开始

用浏览器直接打开 `editor.html` 即可使用，无需安装任何依赖。

## 功能

- **脚本编辑** — 语法高亮、实时校验、节点导航
- **实时预览** — 右侧面板即时预览游戏效果，支持从任意节点开始
- **变量系统** — 赋值、插值、条件判断
- **分支剧情** — 选项分支和条件分支两种模式
- **玩家输入** — 支持 `@input` 让玩家输入名字，代入剧情
- **撤销/重做** — Ctrl+Z / Ctrl+Y，以及上一步/下一步按钮
- **自动保存** — 内容自动保存到浏览器本地存储

## 脚本语法速查

```
@input: player_name = 请输入你的名字    ← 玩家输入（放在脚本最前面）

:: 节点名                              ← 定义剧情节点
角色名: 对话内容                        ← 角色说话
旁白: 场景描述                          ← 旁白/场景描述
{变量名}                               ← 变量插值

[delay:3s]                             ← 延迟
[set 变量:值]                          ← 变量赋值

? 你要说什么？                          ← 选项提示
  + 选项文字 -> 目标节点                ← 选项
[branch]                               ← 条件分支
  变量 > 10 -> 目标节点                 ← 分支规则
  default -> 默认目标                   ← 默认分支

-> 目标节点                            ← 无条件跳转
-> END                                 ← 结局
```
