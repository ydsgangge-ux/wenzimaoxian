# 信号台 · Lifeline 编辑器

一个交互式文字冒险游戏的创作工具，灵感来自 Lifeline（生命线）系列。用简单的脚本语法编写对话剧情，实时预览游戏效果。

## 在线体验

直接打开即可使用，无需安装：

**[https://ydsgangge-ux.github.io/wenzimaoxian/](https://ydsgangge-ux.github.io/wenzimaoxian/)**

> 数据保存在你自己的浏览器里（localStorage），不会上传到任何服务器。关闭页面后内容不会丢失，下次打开自动恢复。

## 功能

- **脚本编辑** — 语法高亮、实时校验、节点导航
- **实时预览** — 右侧面板即时预览游戏效果，支持从任意节点开始
- **变量系统** — 赋值、插值、条件判断
- **分支剧情** — 选项分支和条件分支两种模式
- **玩家输入** — 支持 `@input` 让玩家输入名字，代入剧情
- **撤销/重做** — Ctrl+Z / Ctrl+Y，以及上一步/下一步按钮
- **自动保存** — 内容自动保存到浏览器本地存储
- **导出** — 保存为文本文件或导出为可发布的独立 H5 页面

## 脚本语法速查

```
@input: player_name = 请输入你的名字    ← 玩家输入（放在脚本最前面）

:: 节点名                              ← 定义剧情节点
角色名: 对话内容                        ← 角色说话
旁白: 场景描述                          ← 旁白/场景描述
{变量名}                               ← 变量插值

[delay:3s]                             ← 延迟
[set 变量:值]                          ← 变量赋值

? 你要说什么？                          ← 选项提示
  + 选项文字 -> 目标节点                ← 选项
[branch]                               ← 条件分支
  变量 > 10 -> 目标节点                 ← 分支规则
  default -> 默认目标                   ← 默认分支

-> 目标节点                            ← 无条件跳转
-> END                                 ← 结局
```

## 本地运行

下载 `index.html`，用浏览器打开即可。无需安装任何依赖，无需联网。

## 数据安全

所有创作内容保存在你设备的浏览器本地存储（localStorage）中：
- 不会上传到任何服务器
- 关闭浏览器后内容仍在
- 换设备或换浏览器需要重新输入（可用"保存文本"导出备份）
- 清除浏览器缓存会丢失数据，建议定期导出
